# v0.6 4マッチ「おとどけ」

- 3マッチ、5マッチの方向別ライン、6個以上の虹は維持。4個直線と2×2は、おとどけを生成。内部種別crossを互換用に維持するが、単独十字消去は廃止。
- 隣の果物との交換で飛び立ち、有効な通常果物1個を着地後に消す。アイテム自体も消費。発進マスの隣接障害物にはダメージを与えず、着地点の隣接ダメージは通常ルール。空洞や壁の上を飛行できるが、固定障害物内・無効マス・他の特殊へは着地しない。
- 通常手があるときは候補をランダム順にし、未達成の果物目標を優先。通常手には2×2成立手も含む。
- 通常手ゼロなら各候補で消去・落下・補充・全連鎖を試算。クリアまたは通常手が残る候補を選ぶ。最大12種類の補充系列を探索し、選んだ系列の盤面・進捗・乱数状態・演出イベントをそのまま採用。試算は元盤面を汚さず、シャッフルしない。
- 探索上限まで通常手を作れない場合、別の発動手があれば維持。何もできない場合だけラインアイテムを1つ残し、その旨を表示。単一消去で通常手を作れない2マス領域などでも完全な手詰まりを避ける。すべての配置で1果物の消去だけから通常手が生まれるとは保証しない。
- 他の特殊に巻き込まれたおとどけは、未消去対象から目標優先で1果物へ飛ぶ。この途中発動は個別の先読みをしない。通常の手詰まり救済は全手の解決後に適用。
- 特殊同士の合成範囲は従来のまま維持（おとどけ同士5×5、おとどけ×ライン3行3列、おとどけ×虹は最多色の各3×3）。
- 飛行中も入力ロック。着地後に消去、続いて既存の横流入・落下を表示。動き軽減時は飛行を省略する。
