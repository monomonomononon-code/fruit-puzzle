# v0.4 独立した特殊アイテム

## 影響と採用仕様
- これまで十字・ラインは通常マッチに参加する色付き果物だった。今後は全特殊を `fruit: null` と `special` の組で表す。空きは両方null。通常マッチは特殊を除外する。
- 通常果物の密度は減るが、特殊と通常果物の交換はマッチ不要で成立する。残しておくか今使うかの選択を作る。レベル形状・要求数・種類数は今回は変更しない。
- 生成元の1マスは特殊へ変換し、従来同様に果物収穫へ数えない。特殊の消費も果物数へ加算しない。
- 十字は交換後のアイテム位置と上下左右1マス。ラインは交換方向に合わせた1行/1列。虹は相手の果物を全盤面から消す。どちら側を先に選んでも結果は同じ。
- 他の特殊に巻き込まれたアイテムも一度だけ追加発動。ラインの巻き込み時は生成時の向きを使う。未発動時の向きは内部に残すが、果物属性ではない。
- 特殊同士の合成範囲は維持。色を失う虹×ライン／十字だけは、盤面で最も多い通常果物を選んで各位置から従来の効果を発生。同数は果物一覧順。保護中の通常果物も数え、直撃は保護へ1ダメージ。巻き込まれた虹も同じ対象選択を使う。
- 果物がなく特殊だけの場合、虹の色対象は空集合。ただし交換した特殊は消費され、他の合成の効果・補充は進む。
- 落下・斜め移動は果物と同じ。特殊を空きと誤認して上書きしない。壁・無効マス・固定障害物を通過せず、そこを挟む交換もできない。範囲攻撃は壁を越えて届く。
- 合法手一覧は通常マッチ手と特殊発動手の両方を含み、ヒント・手詰まり判定・操作が同じ一覧を使う。孤立して交換できない特殊だけでは救済を止めない。
- シャッフルでは通常果物だけを再抽選し、特殊の位置・種類・IDを保持。保存は盤面を含まないためデータ移行不要。

計算保護の60連鎖上限に達した場合は、盤面をシャッフルせずその操作と進捗を巻き戻し、再操作を案内する。乱数系列は先へ進む。これは通常の手詰まり救済とは別の異常時保護。

## 検証方針
属性なし・通常マッチ除外、非マッチ発動、左右上下のライン、特殊だけが合法な状態、孤立した特殊、壁、斜め落下、合成全種、収集数・クリア・描画・保存、全20レベルの合法手自動プレイを確認する。
